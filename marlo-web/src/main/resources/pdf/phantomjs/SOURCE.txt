Corresponding source of the bundled PhantomJS 2.1.1 (linux-x86_64)
===================================================================

and QCommandLine, which are licensed under the GNU Lesser General Public
License, version 2.1 (LGPL-2.1.txt in this directory). The BSD licence of
PhantomJS itself is in LICENSE.BSD and the third-party list is in
third-party.txt.

The commit ids were read from the tag with the GitHub contents API
(repos/ariya/phantomjs/contents/src/qt/<submodule>?ref=2.1.1) on 2026-11-24.
