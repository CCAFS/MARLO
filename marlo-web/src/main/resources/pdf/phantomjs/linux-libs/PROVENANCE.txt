Provenance of the shared libraries in this directory (CHG-PPE-T04)
==================================================================

What they are for: the PhantomJS 2.1.1 build shipped for Linux x86_64 needs libfontconfig, libfreetype and their
dependencies. They are a fallback: MARLO extracts them, and sets LD_LIBRARY_PATH for the PhantomJS process it starts and
for no other process, only when PhantomJS does not start with the host's own libraries. They need glibc 2.36 or later
(the highest GLIBC symbol versions needed: libexpat.so.1 GLIBC_2.36; libfontconfig.so.1 and libfreetype.so.6 GLIBC_2.33).
libc and libm are never shipped: the host's are used.

Source: Debian 12 (bookworm), architecture amd64, packages installed from deb.debian.org (bookworm, bookworm-security) in
a debian:bookworm-slim container (/etc/debian_version 12.15) on 2026-11-24, with
  apt-get install --no-install-recommends libfontconfig1 libfreetype6
and copied out with cp -L. The libraries, the package versions and the copyright files come from that one install.

How the upstream values were confirmed: on 2026-11-25, in a new debian:bookworm-slim container, apt-get update and
"apt-cache show <package>=<version>" gave the file name and SHA-256 above for all six versions (none had been
superseded), the six URLs answered 200 when fetched directly, and each downloaded file has the indexed SHA-256.
Unpacking each .deb (dpkg-deb -x) gives libraries whose SHA-256 equals the one stored here: libfontconfig.so.1,
libfreetype.so.6, libexpat.so.1, libpng16.so.16, libbrotlicommon.so.1, libbrotlidec.so.1 and libz.so.1 all match the
list under "SHA-256 of the uncompressed libraries" below.

What was stored: each library unmodified, compressed with gzip -9n, named <soname>.gz. SHA256SUMS holds the SHA-256 of
each library after decompression, in sha256sum format; the application checks every library against it while writing it
and again before use. The copyright files of the six packages are copyright.<package>.

To check: gunzip -c <name>.gz | sha256sum   (compare with SHA256SUMS)
To check a package: sha256sum <file>.deb   (compare with the upstream SHA-256 above)

Licences: each package's terms are in its copyright file (FreeType Licence for libfreetype, permissive licences for
fontconfig, expat, libpng, brotli and zlib). The libraries are separate files, loaded by the PhantomJS
process only, so they can be replaced by the user. The Debian source packages are available from deb.debian.org
(for example: apt-get source libfreetype6 on Debian 12).
